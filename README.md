# 基于 WiFi CSI 的非视觉化手卫生行为感知与智能提醒系统

这是一个面向比赛申报和后续硬件接入的手卫生 AI 智能体项目，用于展示“WiFi CSI + 低成本事件传感器融合”的手卫生行为初筛与提醒流程。

## 打开方式

网页版：直接用浏览器打开 `index.html` 即可运行。

微信小程序版：用微信开发者工具导入本文件夹，AppID 可先选择测试号或使用 `project.config.json` 中的 `touristappid` 预览。

网页端和小程序端默认显示真实设备接入、网关配置、空状态、采集流程和复核队列。填写真实网关地址和点位编号后，客户端会通过 `/health` 和 `/status` 接口获取设备状态与判读结果。

网页版另设一个单次“生成演示事件”按钮，供评审在没有硬件时按固定顺序查看疑似有效、时长不足、待复核和多人干扰场景。演示事件不随机生成、不自动循环，也不会写入网关或后台。

本地联调：

```powershell
& "C:\Users\Owner\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" .\gateway-dev\server.js
```

微信开发者工具中填写：

- 网关地址：`http://127.0.0.1:8787`
- 点位编号：`treatment-room-01`

## 原型能力

- 小程序端：真实设备接入面板、网关配置、最新判读、采集流程、复核队列。
- 网页端：真实网关看板、时长不足统计、设备健康、证据链和复核队列。
- 评审调试：单次生成确定性演示事件，并明确标注“评审演示数据”。
- 后续可接入：ESP32 CSI、压力/按压传感器、区域停留传感器、边缘网关模型。
- 明确系统定位：用于初筛和提醒，不作为最终质控依据。

## 文件说明

- `index.html`、`styles.css`、`web-app.js`：网页版演示原型。
- `app.json`、`app.js`、`app.wxss`、`project.config.json`：微信小程序项目配置。
- `pages/index/`：微信小程序首页页面。
- `api-contract.md`：真实网关接口契约。
- `hardware-integration-roadmap.md`：硬件接入、数据采集和模型训练路线。
- `gateway-dev/server.js`：本地联调用网关服务。
- `site/`：Sites 生产部署项目，首屏直接进入网页版看板。

## 推荐答辩表述

本项目拟构建一种基于 WiFi CSI 与低成本事件传感器融合的非视觉化手卫生行为感知与智能提醒系统，用于在治疗室、ICU 床旁、缓冲间等重点空间内识别疑似手卫生行为，并对未发生或无法判断的情形进行实时提醒。系统不替代人工质控，而作为低隐私风险的前端筛查和辅助管理工具。
